## 2026-05-18 - Replacing chained array methods for large strings\n**Learning:** Chaining `.split('\n').map().filter()` on large strings creates significant memory allocation overhead and garbage collection pauses. This is especially true for parsing batch JSONL responses.\n**Action:** Use a single-pass loop or utility like `parseJsonlArray` (from `src/memory/batch-utils.ts`) for parsing large text data instead of chained array methods.
